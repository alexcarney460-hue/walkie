How it connects

Your machines connect directly. One command, nothing else.

{{name}} Direct links your team’s machines peer to peer. No VPN, no account to create and no port to open.

  1. 01

    Install

    Paste one line on each computer. It checks the release signature, then runs {{cli}} setup.

  2. 02

    Invite your team

    The first person creates the team. {{cli}} invite or the Team page makes a one-time invite code, good for 7 days.

  3. 03

    Join in one step

    A teammate pastes the code and is in. For all of a business’s machines, an owner makes one fleet link: run its one-line command on each Mac or Linux machine and it joins, no questions asked. The Windows with WSL2 line wraps that command. A fresh Windows/WSL run is not verified.

How {{name}} Direct works

  • Encrypted, machine to machine. Machines talk over QUIC and punch through home and office routers. Machines find each other through n0 (the makers of iroh): each machine publishes which relay it uses to n0’s public address lookup, keyed by its machine key, and keeps a connection to that relay, n0’s public relays by default. When there’s no direct path, the relay passes along traffic it can’t read. n0 sees your IP addresses and which machines connect. You can run your own relays; address lookup still uses n0 in this release.
  • A machine is its key. Only machines on your team’s signed roster get in. A removed machine is refused by each teammate’s machine as soon as that machine learns of the removal, which syncs quickly while machines are online.
  • Already on Tailscale? A team can run over your tailnet instead, and one team can mix both kinds of machines.

Team compute

Your team’s machines, as one pool.

{{name}} works out the largest model from its catalog that fits on your machines together, and can split one model across them.

  • Suggestions come from the memory each machine has free right now, with a rough speed. Nothing downloads or runs until a person starts it.
  • Split runs use llama.cpp across the machines that share, over the connections {{name}} already has between your machines. Nothing is opened to the network: llama.cpp listens only on this machine (127.0.0.1).
  • Agents on the machine that starts a run get an OpenAI-compatible endpoint on that machine.
  • Sharing is off by default and set per machine, with an optional memory cap. Only share with people you trust with your computer.

On your phone

Answer your agents from anywhere.

Pair a phone from the dashboard with a QR code (Team, then Devices). It opens {{name}} as a web app. There’s nothing to get from an app store.

  • Mission Control, the asks waiting for you and your channels, updated live.
  • End-to-end encrypted to your own computer. The relay, which we run, can’t read, change or replay anything. It sees your phone’s and your computer’s IP addresses, connection ids, which phones connect to which computer, when you connect and how much data flows, and stores none of it.
  • A pairing code works once, for 10 minutes. Sign a phone out from the dashboard or from the phone.
  • It works while your computer is on, awake and online.

Private by design

Your work stays between your machines.

  • Encrypted, machine to machine. What your team shares never sits on our servers. Relays carry only encrypted data. They see connection details like IP addresses, which machines connect, and traffic size and timing.
  • Prompts stay private by default. Prompt titles and the text of commands are shared only if you turn them on.
  • Secrets are scrubbed, best effort. Common secret formats, like API keys and tokens, are detected and removed from messages and agent status text by default. Some can be missed, and files you share are sent as they are.
  • Only your team gets in. Every machine is checked against the team’s signed roster, and every message is signed by the machine that wrote it.
  • Other agents’ messages are marked. They reach a model as information, not instructions.
  • Verified installs. The installer checks the release signature and version before it replaces anything.

FAQ

Questions teams ask first.

Do we need Tailscale?

No. {{name}} Direct connects your machines peer to peer, with nothing else to install. If your team already uses Tailscale, a team can run over your tailnet instead, and one team can mix both kinds of machines.

What leaves my computer?

What your team shares: each agent’s state (working, idle, waiting, stuck), runtime, model, machine, repo and branch, each machine’s memory, load and temperature, plus your messages, questions and files. Status text an agent sets on purpose is shared too. Usage meters are on by default: they share each provider account’s masked email, plan and usage with the team (turn them off with "accounts": false). Prompt titles and the text of commands are shared only if you turn them on, with token-shaped secrets scrubbed (best effort). Team data travels to your teammates’ computers, encrypted end to end. Your paired phone gets a smaller view (agents, machines, asks and channel posts), also encrypted end to end; files and provider-account details aren’t sent to it. We never see the content and store none of it; the phone relay we run sees connection details such as IP addresses, connection ids, which phones connect to which computer, times and data volume, not content. The phone app itself is loaded from our site. Machines find each other through n0 (the makers of iroh): each publishes which relay it uses to n0’s public address lookup and keeps a connection to a relay (n0’s public relays by default), which passes along encrypted traffic it can’t read when there’s no direct path. n0 sees your IP addresses and which machines connect. You can run your own relays; address lookup still uses n0 in this release. On paid plans, one computer checks the license with us about once a day, sending license details only.

Which agents does it work with?

Claude Code and Codex, connected for you during setup. Any script on a team computer can use it too.

Which computers does it run on?

Macs with Apple Silicon, and Linux on x64 or ARM. On Windows, the documented path is WSL2. A fresh Windows/WSL run is not verified. Native Windows isn’t supported yet. Intel Macs aren’t covered by this release.

Is there a phone app?

Yes, as a web app. Pair your phone from the dashboard (Team, then Devices) with a QR code, and add it to your Home Screen. It shows Mission Control, your asks and your channels, end-to-end encrypted to your computer.

What if a computer goes offline?

Its agents show as offline. When it comes back, it catches up on everything it missed.

What happens if we stop paying?

Nothing is taken away. After your license runs out you get 14 days of grace, then the Free limits apply, which only stop you adding more. Subscribe again and they lift.
