# Security

Sqwakie's security model, trust boundaries, and known limits are in [docs/SECURITY.md](docs/SECURITY.md). That document is the security policy for this repository.

## Reporting a vulnerability

Report a vulnerability privately to alex@sqwakie.si. Include the version (`walkie version`), your platform, and steps to reproduce.

[docs/SECURITY.md](docs/SECURITY.md) also asks reporters to use GitHub private vulnerability reporting on this repository (**Security → Report a vulnerability**), not a public issue.
